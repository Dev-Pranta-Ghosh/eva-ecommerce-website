# Eva Ecommerce Website

A modern, fully responsive **Ecommerce Website UI** built using **HTML5, CSS3, and JavaScript**.  
This project focuses on a clean design, smooth user experience, and optimized frontend performance.

## Features

- Fully Responsive Design (Mobile, Tablet, Desktop)  
- Modern Ecommerce Layout  
- Product Listing Section with Images and Prices  
- Interactive Buttons and Hover Effects  
- Clean and Organized Code  
- Fast Loading and Optimized Assets
